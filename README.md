#  Password Strength Checker

A simple Python command-line application that checks the strength of a password based on different security rules.

##  Features

- Checks if password contains spaces
- Counts uppercase letters, lowercase letters, digits, and special characters
- Validates password strength based on multiple criteria
- Gives feedback on missing requirements
- Classifies password as:
  - WEAK
  - MEDIUM
  - STRONG
  - VERY STRONG

##  Password Rules

A strong password must have:
- At least 10 characters
- At least 3 uppercase letters
- At least 3 lowercase letters
- At least 3 digits
- At least 1 special character
- No spaces allowed

##  How to Run

## bash
python password_checker.py
